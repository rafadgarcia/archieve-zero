# Câmera de Aura

> O equipamento registra uma segunda exposição mesmo quando o obturador permanece fechado. A imagem residual não corresponde à cena observada.

## Protocolo de observação

- Manter o núcleo isolado durante o transporte.
- Registrar horário e posição de cada exposição.
- Não interpretar assinaturas sem uma segunda evidência.
