# Ciclo nº 17?

A anotação possui uma interrogação na fonte. O número de ciclos não é tratado aqui como uma contagem confirmada.

## Frases registradas no quadro

- A Membrana não desapareceu.
- O erro foi assumir que somos o primeiro mundo.
- Origem ≠ Plano Beta.
- Inúmeros outros universos.
- Kian não é a origem.
- Primeiro mundo: localização desconhecida.
- Eles atravessaram antes de nós.
- Cada ruptura aumenta a probabilidade de outra.

## Sequência diagramada

Estável → Degradação → Ruptura → Colapso → Reinício.

A presença dessas frases no quadro é o registro disponível. Seu significado e a validade de cada hipótese ainda precisam de investigação; o Archive não preenche essas lacunas.
