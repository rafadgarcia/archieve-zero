# Projeto K — linha de pesquisa

A proposta é preparar Oshino para compreender e neutralizar condições específicas de Kian, em vez de depender apenas de dano ou poder bruto.

## Método proposto

Observar → catalogar → relacionar → compreender → testar → explorar.

Conhecimento é a identidade conceitual escolhida para o personagem no dossiê. Isso não atribui automaticamente esse elemento a todas as evidências investigadas.

## Caminhos oferecidos para o timeskip

- Documentos históricos, poderes e fraquezas de Kian.
- Lugares, pessoas, experimentos e criaturas relevantes.
- Relíquias e itens amaldiçoados: saber que existem não significa possuí-los.
- Treinamento de perícias baseado nas descobertas.

A hipótese extrema de transferência ou absorção permanece uma possibilidade narrativa dependente da campanha e do mestre, não uma capacidade adquirida.
